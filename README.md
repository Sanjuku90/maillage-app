# Maillage V1.1 (Android) — messagerie Bluetooth mesh sans internet

## Obtenir l'APK sans PC
1. Crée un dépôt GitHub, envoie-y tout le contenu du zip (dossier .github compris).
2. Onglet Actions > "Build APK" > Run workflow.
3. Quand c'est vert : run > Artifacts > maillage-apk > installe l'APK.

## Utilisation
Même mot de passe de canal sur tous les téléphones, Bluetooth activé. Retour (←) = l'appli reste active en arrière-plan de l'écran ; "Quitter" coupe le maillage.
Messages : 200 caractères, 7 sauts max, conservés 1 h pour les nouveaux voisins, historique gardé sur le téléphone.
