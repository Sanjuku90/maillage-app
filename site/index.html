Écrivez sans réseau.

Maillage relie les téléphones entre eux par Bluetooth. Chaque téléphone relaie les messages des autres : pas d’internet, pas de forfait, pas de compte.

Installer sur AndroidVoir le principe

Comment ça marche

  1. Choisis un mot de passeLes personnes qui le connaissent lisent le canal. Pour les autres, c’est illisible.
  2. Les téléphones se trouventDès qu’ils sont à portée, ils se connectent tout seuls en Bluetooth.
  3. Le message sauteDe téléphone en téléphone, jusqu’à 7 sauts, pour aller bien plus loin que la portée d’un seul.

Pensé pour les endroits sans réseau

Aucun réseau requisFestival, randonnée, panne, métro : ça marche sans antenne ni Wi-Fi.
Messages chiffrésLes messages sont chiffrés avec le mot de passe du canal avant de quitter ton téléphone.
Rien n’est perduUn message est gardé 1 h et rejoué aux téléphones qui arrivent après.
Aucun compteNi numéro, ni e-mail. Un pseudo suffit.

L’app, de près

Un seul écran : le canal, les messages et leur nombre de sauts. Ce que tu vois ici est la même interface que dans l’app Android.

Installer

  1. Mets le projet sur GitHub et lance « Build APK » dans l’onglet Actions.
  2. Télécharge l’APK obtenu (Artifacts) sur ton téléphone Android.
  3. Autorise l’installation d’applications inconnues, puis ouvre l’APK.
  4. Active le Bluetooth, choisis un pseudo et le même mot de passe que tes amis.
